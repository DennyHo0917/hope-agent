# Hope Agent 0.49.0 — 连接与桌面操作更顺畅

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.49.0/docs/release-notes/v0.49.0.en.md)

> 发布日期：2026-09-17

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.49.0/CHANGELOG.md#0490---2026-09-17)。

## 连接需要登录的远程 MCP 服务

只填写服务器网址时，如果远程服务要求登录，连接卡片现在会提供授权入口。点击授权后，应用会按照服务器支持的方式完成登录；遇到不支持的方式会明确提示。原有连接失败后也可再次从卡片发起授权。

## 关闭 macOS 全屏窗口

在全屏状态下关闭主窗口时，应用会等退出全屏的过渡完成后再隐藏窗口，降低留下空白桌面空间的风险。若在过渡中从 Dock 或托盘重新打开，待隐藏操作会取消。

## 给外部知识空间授予写入权限

外部知识空间开启“允许写入外部库”后，可以在会话或项目中明确选择“读写”挂载。开启外部写入和授予挂载权限仍是两步操作；未开启写入的库保持只读，项目继承的权限需在项目设置中修改。
