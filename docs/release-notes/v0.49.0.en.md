# Hope Agent 0.49.0 — Smoother connections and desktop controls

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.49.0/docs/release-notes/v0.49.0.md) · **English**

> Released: September 17, 2026

> See the [changelog](https://github.com/shiwenwen/hope-agent/blob/v0.49.0/CHANGELOG.md#0490---2026-09-17) for the complete list of changes.

## Sign in to remote MCP services

When a remote service asks you to sign in after you enter its URL, its connection card now offers an authorization action. Click it to start sign-in using a method the service supports; unsupported methods produce a clear error. You can also retry authorization from the card after an initial connection failure.

## Close a full-screen window on macOS

Closing the main window while it is full-screen now waits for the full-screen transition before hiding it, reducing the chance of a blank desktop Space. Reopening it from the Dock or tray during the transition cancels the pending hide.

## Grant write access to an external knowledge space

After enabling external writes for a knowledge space, you can explicitly choose a read-write mount in a conversation or project. Enabling writes and granting mount access remain separate actions. Spaces without external writes stay read-only, and inherited project permissions are changed in project settings.

## Read update notes

The in-app update notice no longer includes a draft-review placeholder, leaving just this release's notes.
