## See what changed in a file

Click a changed-file label in a reply, or a file with a change record in the workspace, to see the saved before-and-after difference. Newly created files show all their added content. The file menu still offers a preview of the current file.

When an older record has no saved difference, the app says so instead of presenting the current file as the historical change.
