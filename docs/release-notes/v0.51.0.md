## Intel Mac 可直接安装原生版本

使用 Intel 处理器的 Mac 现在可以重新下载专用的 x64 安装包，不必再依赖不兼容的 Apple 芯片版本。Apple 芯片 Mac、Windows 和 Linux 的现有下载方式保持不变。

Intel 安装包会在主版本发布后独立生成；若刚发布时暂未看到，请稍后刷新下载页面。
