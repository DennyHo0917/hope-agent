## 查看改写了什么

点击回复中的改写文件标签或工作台里有改写记录的文件，可以直接查看当时保存的修改前后差异；新建文件会显示全部新增内容。需要查看文件当前内容时，仍可使用文件菜单中的预览入口。

如果历史记录没有保存差异内容，界面会明确提示，而不会把文件当前内容误当成当时的改动。
