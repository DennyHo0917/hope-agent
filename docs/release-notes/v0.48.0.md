# Hope Agent 0.48.0 — 网页使用与外部记忆更可靠

> **简体中文** · [English](https://github.com/shiwenwen/hope-agent/blob/v0.48.0/docs/release-notes/v0.48.0.en.md)

> 发布日期：2026-09-15

> 完整变更见 [更新日志](https://github.com/shiwenwen/hope-agent/blob/v0.48.0/CHANGELOG.md#0480---2026-09-15)。

## 搜索与网页导入

网页搜索的日志和错误提示不再重复记录你的搜索词、请求地址或搜索服务返回的原始正文。导入网页到知识空间或读取远程媒体时，跳转到受限网络地址的请求会被阻止。

## 连接 OpenViking 记忆服务

使用 OpenViking 外部记忆时，应用会根据已识别的服务端版本读取当前用户的记忆，兼容 0.4.17 前后的地址变化。无法确认兼容版本时会停止同步；遇到这种情况，请先在外部记忆设置中检查连接与服务版本。

## 判断领域任务是否完成

新建的内置领域评测会逐条检查证据是否包含有效信息。缺少内容或格式不正确的证据不再被计入完成数量，便于发现仍需补充的材料；历史评测保留原有口径。
