## Install the native version on an Intel Mac

Intel Mac users can once again download a dedicated x64 installer instead of relying on an incompatible Apple silicon build. Existing downloads for Apple silicon Macs, Windows, and Linux are unchanged.

The Intel installer is prepared independently after the main release. If it is not visible immediately, refresh the downloads page shortly afterward.
