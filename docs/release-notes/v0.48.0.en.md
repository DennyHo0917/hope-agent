# Hope Agent 0.48.0 — More reliable web access and external memory

> [简体中文](https://github.com/shiwenwen/hope-agent/blob/v0.48.0/docs/release-notes/v0.48.0.md) · **English**

> Released: 2026-09-15

> See [the changelog](https://github.com/shiwenwen/hope-agent/blob/v0.48.0/CHANGELOG.md#0480---2026-09-15) for the full list.

## Search and import web pages

Web search logs and error messages no longer repeat your search terms, request addresses, or raw responses from search services. When importing a page into a knowledge space or reading remote media, requests that redirect to restricted network addresses are blocked.

## Connect to OpenViking memory

For OpenViking external memory, the app uses the detected server version to read the current user's memories, supporting the address change introduced in 0.4.17. Sync stops when a compatible version cannot be confirmed. If this happens, check the connection and server version in external memory settings.

## Review domain task completion

New built-in domain evaluations check each piece of evidence for usable information. Empty or incorrectly formatted evidence no longer counts toward completion, making missing material easier to identify. Historical evaluations keep their original criteria.
